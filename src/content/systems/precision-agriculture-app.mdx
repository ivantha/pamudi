## The brief

Substrate sensors produce more numbers than anyone can read. A grower walking a
controlled-environment facility needs to know which room is drifting, and needs to know
it from a phone held in one hand, in a room where the light is wrong for reading a
screen.

The application pairs sensor hardware with irrigation and crop-management software. The
design problem is not the data, which already exists. It is compression: how much of a
facility can be made legible at a glance, and where the glance has to turn into a
proper look.

## A facility on one screen

Every room in the facility is a row, and every row carries the same six readings in the
same six positions and the same six colours. Scanning down the column is what finds the
outlier, which is why the values are never re-ordered per room.

Colour does the first pass and is never the only signal: each reading keeps its unit
under the number, so a value that reads wrong can be checked without tapping.

## The room, and what the chart is allowed to say

Inside a room the same values become series. The chart is drawn dark because these
rooms are dark, and the lines keep the colours the chips used a screen earlier, so the
legend is something you already learned rather than something you have to read.

The range switcher sits at the foot, in thumb reach, with the growing period itself
("From Start") offered beside the calendar ranges. A grower's question is more often
"since when did this start" than "what did the last 24 hours do".

## Choosing what to plot

Six series on one chart is the maximum this design will draw, so which six is a real
decision and gets a real screen. The picker splits climate from soil and substrate,
because that is how the sensors are physically installed, and it puts the current
target band under each name so the choice is informed.
