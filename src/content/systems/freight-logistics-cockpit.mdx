argument:
  - label: The problem
    lead: The building was known; the pallet was not.
    paragraphs:
      - >-
        Location detection produced far more state than any screen had been
        designed to hold: every rack, aisle and bay, in every facility, changing
        continuously. Planners wanted the network view. Floor staff wanted the
        one aisle in front of them.
      - >-
        Existing tooling answered neither well. Wide tables scrolled sideways
        past the point of use, and per-site views hid the exceptions that
        actually needed a decision.
  - label: The approach
    lead: One grid, two reading distances.
    paragraphs:
      - >-
        The rack grid is the primary object, and it is built to be scanned
        rather than read: occupancy and exception states legible at a glance,
        identifiers legible on approach. Filters narrow the same grid instead of
        switching to a different layout.
      - >-
        Because the operator runs in dozens of countries, the type scale, number
        formatting and label lengths were specified for translation and for
        longer location codes from the outset, and the components were written
        against React for the build team.
